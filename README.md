# Графический редактор

Простой графический редактор, написанный на C++ с использованием Qt6.

## Возможности
- Рисование линий, прямоугольников, эллипсов
- Свободное рисование (ручка)
- Выбор цвета и толщины линии
- Сохранение и загрузка рисунков (.draw)

## Технологии
- C++17
- Qt6
- CMake / qmake
- Собственный умный указатель SmartPtr

## Как собрать и запустить
1. Установите Qt Creator и Qt6
2. Клонируйте репозиторий:
  git clone https://github.com/YeliseyLebedev/2026_PV-241_YELISEY_3.git
